## How to Use

- **Browse by topic** using the Table of Contents above
- **Search instantly** with `Ctrl+F` / `Cmd+F` using keywords, tags, or resource names
- **Resource types** are labeled for fast scanning:
  - 📄 Article / Blog
  - 🎓 Tutorial / Course
  - 🛠️ Tool / Software
  - 📑 Research Paper
  - 🐙 GitHub Repo
  - 🎥 Video / Podcast
  - 🔗 Link / Reference
- ⭐ **Star** = personal favorite or must-read
